# Аналитика каталога стримингового сервиса

Учебный проект: набор функций для анализа каталога фильмов (рейтинги, возраст,
жанры, актеры) и итоговый консольный отчет.

## Требования

- Python 3.12
- [uv](https://docs.astral.sh/uv/)

## Запуск

```bash
uv run python catalog_analysis.py
```

## Проверка кода

```bash
uv run ruff check .
```
